## Maker Comment (First Comment)

```
Hi Product Hunt 👋

I've been using Claude Code heavily across .NET and Azure projects and got tired 
of re-establishing the same context at the start of every session: what Clean 
Architecture means here, how I want Azure structured, which OWASP checks to run 
before shipping.

These three plugins package that context once. Install and it's always there.

The one I use most: Clean Architecture scaffolding. New feature request comes in, 
one command creates the full layer stack with the right dependencies. The one I 
run least frequently but matter most: the OWASP LLM auditor, before any AI 
feature goes to anyone else.

All three are open source. Happy to answer questions about how Claude Code plugins 
work under the hood or the specific implementation choices.

GitHub: github.com/waelouf/claude-code-powerups
```
