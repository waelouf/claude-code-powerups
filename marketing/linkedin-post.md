```
I got tired of re-explaining the same project context to Claude Code every time I started something new.

On the third .NET project, I packaged the context into a plugin.

Claude Code Powerups is a set of three plugins for common developer tasks:

**Clean Architecture Powerup** — for .NET projects with Clean Architecture (FastEndpoints, Entity Framework). Instead of explaining your layer structure at the start of every session, the plugin carries that context. Scaffolds features across all layers, audits boundary violations, migrates existing code.

**Azure Architect Powerup** — infrastructure provisioning, CI/CD pipelines, and cost optimization for Azure. The plugin knows Azure patterns; you describe what you need.

**OWASP LLM Top 10 Security Auditor** — reviews AI applications for the 11 OWASP LLM security vulnerabilities. Useful if you're building on top of LLM APIs and want a systematic check.

Install with claude-code plugin install. All three are free and open source.

github.com/waelouf/claude-code-powerups
```
