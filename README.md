## 🚀 Installation

### Install the Marketplace

```bash
claude-code plugin install waelouf/claude-code-powerups
```

This will make all powerups in this marketplace available for installation.

### Install Individual Powerups

After installing the marketplace, you can install specific powerups:

```bash
# Install Clean Architecture Powerup
claude-code plugin install waelouf/cc-powerup-clean-architecture

# Install Azure Architect Powerup
claude-code plugin install waelouf/cc-powerup-azure-architect

# Install OWASP LLM Security Auditor
claude-code plugin install waelouf/cc-powerup-owasp-llm
```

Or install all powerups at once:

```bash
claude-code plugin install waelouf/cc-powerup-clean-architecture waelouf/cc-powerup-azure-architect waelouf/cc-powerup-owasp-llm
```

## 🔍 What Are Powerups?

Powerups are specialized Claude Code plugins that extend Claude's capabilities with domain-specific expertise. Each powerup includes:

- **Skills** - Custom commands and workflows
- **Agents** - Specialized AI agents for specific tasks
- **Tools** - Domain-specific utilities and helpers
- **Knowledge** - Curated best practices and patterns
